# 📱 PWA Guide - FinTracker

## Что такое PWA?

**Progressive Web App (PWA)** - это веб-приложение, которое работает как нативное мобильное приложение:
- ✅ Устанавливается на домашний экран
- ✅ Работает офлайн
- ✅ Быстрая загрузка
- ✅ Push-уведомления
- ✅ Полноэкранный режим

---

## 🎉 Что было реализовано

### ✅ Основные компоненты

1. **manifest.json** - манифест приложения
   - Информация о приложении (название, описание, иконки)
   - Настройки отображения (standalone mode)
   - Ярлыки для быстрых действий
   - Цветовая схема

2. **service-worker.js** - Service Worker для офлайн режима
   - Кэширование статических файлов
   - Офлайн поддержка
   - Автоматические обновления
   - Синхронизация в фоне

3. **PWA мета-теги в index.html**
   - iOS совместимость
   - Android совместимость
   - Windows совместимость
   - Цвета темы

4. **Логика регистрации в app.js**
   - Автоматическая регистрация Service Worker
   - Баннер установки приложения
   - Уведомления об обновлениях
   - Обработка установки

## 🚀 Как установить приложение

### На Android (Chrome, Edge, Samsung Internet)

1. Откройте приложение в браузере
2. Появится баннер "Установите FinTracker на устройство"
3. Нажмите **"Установить"**
4. Или: нажмите меню (⋮) → "Установить приложение"
5. Приложение появится на домашнем экране

### На iOS (Safari)

1. Откройте приложение в Safari
2. Нажмите кнопку "Поделиться" (⎙)
3. Выберите **"На экран Домой"**
4. Нажмите **"Добавить"**
5. Приложение появится на домашнем экране

### На Desktop (Chrome, Edge)

1. Откройте приложение в браузере
2. В адресной строке появится иконка установки (+)
3. Нажмите на иконку
4. Или: нажмите меню (⋮) → "Установить FinTracker..."
5. Приложение откроется в отдельном окне

## 🔧 Настройка и кастомизация

### Изменить цвета приложения

Отредактируйте `manifest.json`:

```json
{
  "theme_color": "#667eea",        // Цвет темы (адресная строка)
  "background_color": "#ffffff"    // Цвет фона при загрузке
}
```

### Изменить название

Отредактируйте `manifest.json`:

```json
{
  "name": "Ваше название",         // Полное название
  "short_name": "Короткое"         // Короткое название (под иконкой)
}
```

### Добавить ярлыки

Отредактируйте `shortcuts` в `manifest.json`:

```json
{
  "shortcuts": [
    {
      "name": "Добавить расход",
      "url": "/?action=add-expense",
      "icons": [...]
    }
  ]
}
```

### Изменить кэш-стратегию

Отредактируйте `service-worker.js`:

```javascript
// Увеличьте версию при изменениях
const CACHE_VERSION = 'v1.0.1';

// Добавьте файлы для кэширования
const STATIC_CACHE_URLS = [
  '/',
  '/index.html',
  // ... ваши файлы
];
```

## 🧪 Тестирование PWA

### 1. Chrome DevTools

1. Откройте DevTools (F12)
2. Перейдите во вкладку **"Application"**
3. Проверьте:
   - **Manifest** - корректность манифеста
   - **Service Workers** - статус регистрации
   - **Cache Storage** - кэшированные файлы
   - **Lighthouse** - аудит PWA

### 2. Lighthouse Audit

1. Откройте DevTools (F12)
2. Перейдите во вкладку **"Lighthouse"**
3. Выберите **"Progressive Web App"**
4. Нажмите **"Analyze page load"**
5. Проверьте оценку (должно быть >90)

### 3. Тест офлайн режима

1. Откройте приложение
2. В DevTools перейдите в **"Network"**
3. Включите **"Offline"** режим
4. Обновите страницу (F5)
5. Приложение должно работать!

## 🔔 Push-уведомления (в разработке)

Service Worker уже поддерживает push-уведомления. Для активации нужно:

1. Настроить Firebase Cloud Messaging или другой сервис
2. Добавить логику подписки в app.js
3. Настроить backend для отправки уведомлений

Код уже готов в `service-worker.js`:
```javascript
self.addEventListener('push', (event) => {
  // Обработка уведомлений
});
```

## 🐛 Решение проблем

### Приложение не устанавливается

**Причины:**
1. Нет HTTPS (кроме localhost)
2. Отсутствуют иконки
3. Некорректный manifest.json
4. Service Worker не зарегистрирован

**Решение:**
1. Используйте HTTPS или localhost
2. Сгенерируйте иконки через `generate-icons.html`
3. Проверьте JSON на ошибки
4. Откройте DevTools → Application → Service Workers

### Service Worker не работает

**Причины:**
1. Ошибки в коде service-worker.js
2. Неверный путь к файлу
3. Браузер не поддерживает

**Решение:**
1. Откройте DevTools → Console
2. Проверьте путь: `/service-worker.js`
3. Используйте современный браузер

### Кэш не обновляется

**Причины:**
1. Не изменена версия кэша
2. Старый Service Worker активен

**Решение:**
1. Измените `CACHE_VERSION` в service-worker.js
2. DevTools → Application → Service Workers → "Unregister"
3. Обновите страницу (Ctrl+Shift+R)

### Офлайн режим не работает

**Причины:**
1. Файлы не добавлены в STATIC_CACHE_URLS
2. Service Worker не активен

**Решение:**
1. Добавьте файлы в массив кэширования
2. Проверьте статус в DevTools → Application

## 🔄 Обновление PWA

### Автоматическое обновление

1. Измените код (app.js, styles.css, index.html)
2. Увеличьте `CACHE_VERSION` в service-worker.js
3. Закоммитьте и задеплойте
4. Пользователи увидят баннер обновления через ~60 секунд
5. После клика "Обновить" - новая версия применится

### Ручное обновление

```javascript
// В консоли браузера
navigator.serviceWorker.getRegistration().then(reg => {
  reg.update();
});
```
