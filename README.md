# 💰 FinTracker - Приложение для учета финансов

Современное веб-приложение для отслеживания личных финансов с минималистичным дизайном и полной адаптивностью для мобильных устройств и компьютеров.

![FinTracker](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ Основные возможности

- 📊 **Визуализация расходов** - интерактивные графики для анализа трат по категориям
- 💸 **Учет доходов и расходов** - быстрое добавление транзакций
- 📱 **Адаптивный дизайн** - идеальная работа на мобильных и десктопах
- 🌓 **Темная/светлая тема** - автоматическое сохранение предпочтений
- 📅 **Фильтры по периодам** - просмотр данных за месяц, год или все время
- 🏷️ **Категории транзакций** - организация по типам расходов
- 💾 **Локальное хранилище** - все данные хранятся в браузере
- ⚡ **Быстрая работа** - без сервера, все работает локально
- 🎨 **Минималистичный UI** - чистый и современный интерфейс

## 🚀 Быстрый старт

### 🎯 Простейший способ - Автоматический запуск

Мы создали удобные скрипты для автозапуска на **всех платформах**! Просто запустите один файл:

#### 🐧 Linux / 🍎 MacOS
```bash
# Клонируйте репозиторий
git clone https://github.com/athebyme/finance-tracking-app.git
cd finance-tracking-app

# Запустите автоматический скрипт
./start.sh
# или
python3 start.py
```

#### 🪟 Windows
```bash
# Клонируйте репозиторий
git clone https://github.com/athebyme/finance-tracking-app.git
cd finance-tracking-app

# Двойной клик по файлу или запустите в командной строке
start.bat
# или
python start.py
```

**Что делают скрипты:**
- ✅ Автоматически находят свободный порт
- ✅ Запускают локальный HTTP сервер
- ✅ Открывают браузер с приложением
- ✅ Красиво форматируют вывод с цветами
- ✅ Показывают URL для доступа из сети

### 🐳 Docker - Запуск в контейнере

Самый простой способ для продакшен-окружения:

```bash
# Способ 1: Автоматический скрипт (рекомендуется)
./docker-run.sh

# Способ 2: Docker Compose вручную
docker-compose up -d

# Способ 3: Make команды
make docker-up

# Способ 4: npm scripts
npm run docker:start
```

Приложение будет доступно на `http://localhost:8080`

**Преимущества Docker:**
- 🔒 Изолированное окружение
- 📦 Легковесный образ (nginx:alpine ~10MB)
- 🚀 Быстрый старт и остановка
- ♻️ Автоматический перезапуск
- 💪 Готово для продакшена

**Docker команды:**
```bash
docker-compose up -d        # Запустить
docker-compose down         # Остановить
docker-compose logs -f      # Просмотр логов
docker-compose restart      # Перезапустить
make docker-build           # Пересобрать образ
```

## 📱 Использование

### Добавление транзакции

1. Введите сумму в поле "Сумма"
2. Добавьте описание транзакции
3. Выберите категорию из списка
4. Укажите дату (по умолчанию - сегодня)
5. Нажмите "+ Доход" или "− Расход"

### Просмотр статистики

- **Общий баланс** отображается на главной карточке
- **Доходы и расходы** показаны отдельно с иконками
- **График** показывает распределение расходов по категориям
- Переключайте периоды: **Месяц**, **Год**, **Все время**

### Фильтрация транзакций

Используйте кнопки фильтров для отображения:
- Всех транзакций
- Только доходов
- Только расходов

### Темная тема

Нажмите кнопку с иконкой солнца/луны в правом верхнем углу для переключения темы.

## 🎨 Дизайн

### Цветовая схема

**Светлая тема:**
- Фон: `#ffffff`, `#f8f9fa`
- Текст: `#1a1a1a`, `#6c757d`
- Акценты: Градиент `#667eea` → `#764ba2`

**Темная тема:**
- Фон: `#0f0f0f`, `#1a1a1a`
- Текст: `#ffffff`, `#a0a0a0`
- Акценты: Тот же градиент

### Типографика

- Шрифт: **Inter** (от Google Fonts)
- Адаптивные размеры для разных устройств
- Антиалиасинг для улучшенной читаемости
