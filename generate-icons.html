🎨 PWA Icon Generator

Генератор иконок для FinTracker PWA приложения

📋 Инструкция:

  1. Нажмите "Скачать все иконки" чтобы сохранить все размеры
  2. Поместите скачанные PNG файлы в корневую папку проекта
  3. Иконки будут автоматически использоваться PWA приложением
  4. Для iOS добавьте иконки в папку проекта и перезапустите приложение
